## 改动记录

### 知识集页面交互与样式改造（P0 + 部分P1）

- 目标模块：`frontend/src/pages/KnowledgeSet/**`
- 核心改动：
  - 页面结构改为三层：工具层（搜索/筛选/操作）→ 结果层（数量/分页）→ 内容层（列表/状态）
  - 新增筛选能力：
    - 搜索框（关键词）
    - 快捷筛选（状态/可见性）
    - 已选条件 chips（可单个关闭）
    - 一键清空（重置筛选与分页）
  - 标准化三态：
    - loading：居中 Spin
    - empty：统一 Empty
    - error：统一 Result(error) + 重试按钮
  - 样式统一：
    - 统一容器、间距、圆角、边框
    - 统一输入与按钮布局规格
    - 卡片信息层级与底部元信息规范化
  - P1 增量：
    - 高级筛选抽屉（状态/可见性）
    - URL query 同步（keyWord/status/visibility/page/pageSize）
    - 移动端关键适配（断点下单列卡片、抽屉宽度 100%、分页小尺寸）
