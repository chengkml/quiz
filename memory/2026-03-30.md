## 需求管理页面 React #130 修复
- 现象：线上 Requirement 页面打开即报 `Minified React error #130`，错误方向为 `Element type is invalid / got undefined`。
- 定位结论：根因在前端 `frontend/src/pages/Requirement/api/index.ts` 与 `frontend/src/pages/Requirement/index.tsx` 的近期改动把模块本身写坏，不是后端问题。
  - `api/index.ts` 中出现未定义的 `designRequirement` 被写入 default export，同时文件尾部还残留一段非法文本 `tList, ...`，模块导出结构已损坏。
  - `index.tsx` 文件尾部存在重复/残缺 JSX 与重复 `export default Requirement;`，并夹杂重复 `case "design"` 等异常拼接内容，导致 Requirement 页面模块解析/导出不稳定。
- 处理策略：按“最小修复”将 Requirement 前端两个文件回退到当前稳定基线，先恢复页面可正常加载；不扩散到后端。
- 验证：执行 `cd frontend && npm run build`，等待结果中。
- 上线状态：待上线。
