- 改动文件：
  - `frontend/src/pages/Requirement/index.tsx`
  - `frontend/src/pages/Requirement/style/index.less`
- 改动说明：
  - 将标题列的 `Typography.Link` 替换为原生按钮样式链接，避免渲染 `undefined` 组件。
  - 新增 `.requirement-title-link` 样式，保持表格内点击态与现有视觉一致。
- 验证：
  - `cd frontend && npm run build` 通过（webpack compiled with 2 warnings，均为既有体积/less 警告）
  - `cd backend && GRADLE_OPTS='-Dorg.gradle.native=false' gradle classes` 通过
- 风险：
  - 低。仅影响 Requirement 列表标题点击节点的渲染方式，不涉及接口、状态流转和数据结构。
