---

此技能用于自动化前端代码的编译验证。如果编译失败，它会引导 AI 分析报错堆栈并尝试修正源代码。

## 使用方法

1. **执行检查**：
AI 应当切入项目前端目录并执行以下命令：
```bash
cd d:\idea_repo\quiz\frontend
npm run build
```

2. **结果处理逻辑 (AI 决策流)**：
* **若命令执行成功 (Exit Code 0)**：
    * 确认编译通过，任务完成。

* **若命令执行失败 (Exit Code 非 0)**：
    * **第一步 (分析)**：提取输出中的 Error 信息，特别是 TypeScript 错误 (TSxxxx) 或 Webpack 构建错误。
    * **第二步 (定位)**：读取报错信息中提到的具体文件及行号。
    * **第三步 (修复)**：理解错误原因（如：类型不匹配、组件属性错误、缺少 import 等），并修改对应的 TSX/TS/CSS 文件。
    * **第四步 (验证)**：修复后，**自动重新运行**此 Skill，直到构建成功。

## 提示 (Tips)

* **类型检查**：如果是 TypeScript 类型错误，报错通常包含 `TS` 开头的错误码（如 `TS2322`）。
* **依赖检查**：若出现 `Module not found`，请检查 `package.json` 或 `import` 路径。
* **增量修复**：前端构建错误可能很多，建议每次修复最明显的一个或一类错误，然后重新运行。
