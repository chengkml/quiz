此技能用于自动化后端代码的编译验证。如果编译失败，它会引导 AI 分析报错堆栈并尝试修正源代码。

## 使用方法

1. **执行检查**：
AI 应当切入项目后端目录并执行以下命令：
```bash
cd d:\idea_repo\quiz\backend
.\gradlew.bat compileJava

```


2. **结果处理逻辑 (AI 决策流)**：
* **若输出包含 `BUILD SUCCESSFUL**`：
* 确认编译通过，任务完成。


* **若输出包含 `BUILD FAILED**`：
* **第一步 (分析)**：提取输出中所有以 `error:` 开头的行。
* **第二步 (定位)**：读取报错信息中提到的具体文件及行号。
* **第三步 (修复)**：理解错误原因（如：缺少分号、变量未定义、类型不匹配等），并修改对应的 Java 文件。
* **第四步 (验证)**：修复后，**自动重新运行**此 Skill，直到构建成功。





## 提示 (Tips)

* **依赖检查**：若报错提示 `package ... does not exist`，请检查 `build.gradle` 中的依赖配置是否完整。
* **测试代码**：若需同时验证单元测试，请将命令替换为 `.\gradlew.bat testClasses`。
* **自动进化**：本技能仅针对语法和编译错误。对于复杂的逻辑 bug，请在运行通过后配合“单元测试 Skill”进一步验证。
