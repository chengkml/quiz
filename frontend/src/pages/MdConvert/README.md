# Markdown 转换工具使用指南

## 功能概述

Markdown 转换工具是一个强大的文档转换平台，支持将 Markdown 格式的文档转换为以下多种格式：

- **Word (DOCX)**：保留格式和样式的 Microsoft Office 文档
- **PDF**：便于分享、打印和归档的便携式文档格式
- **HTML**：可在网页中直接使用的超文本标记语言

## 核心特性

### 1. 完整的 Markdown 语法支持

支持标准 Markdown 语法，包括：

- **标题**：H1-H6 多级标题
- **文本样式**：粗体、斜体、删除线
- **列表**：有序列表和无序列表，支持嵌套
- **代码**：行内代码和代码块，支持语言高亮
- **引用**：块级引用
- **表格**：Markdown 表格语法
- **链接和图片**：超链接和图片嵌入
- **分隔线**：水平线分隔

### 2. 多格式输出

#### Word 输出 (DOCX)
- 保留 Markdown 的结构和基本格式
- 生成的文档可直接在 Microsoft Office 中编辑
- 支持自定义文件名
- 默认采用标准页面大小（A4）

#### PDF 输出
- 使用 OpenHTML2PDF 库高质量转换
- 支持复杂的布局和样式
- 生成的 PDF 可靠性高，适合正式文档
- 包含完整的样式信息，保证视觉一致性

#### HTML 输出
- 实时预览转换结果
- 支持两种视图：渲染预览和源代码查看
- 可复制 HTML 代码用于网页集成
- 支持下载为 HTML 文件

### 3. 实时预览

- HTML 转换后即时显示预览效果
- 分为"预览"和"HTML 代码"两个标签页
- 所见即所得的用户体验

### 4. 文件管理

- 自定义输出文件名
- 自动添加相应的文件扩展名（.docx、.pdf、.html）
- 支持一键下载到本地

## 使用步骤

### 基本流程

1. **输入 Markdown**
   - 在左侧的"Markdown 内容"卡片中输入或粘贴您的 Markdown 文本
   - 可以点击"加载示例"查看示例内容

2. **配置文件名**
   - 在"转换配置"卡片中分别设置 Word 和 PDF 的文件名
   - 输入文件名时不需要包含扩展名，系统会自动添加

3. **选择转换格式**
   - 点击"转换为 Word"导出为 DOCX 格式
   - 点击"转换为 PDF"导出为 PDF 格式
   - 点击"转换为 HTML（预览）"查看 HTML 格式和效果预览

4. **下载文件**
   - 转换完成后，文件会自动下载到本地
   - HTML 预览可以复制代码或下载为 HTML 文件

```markdown

## 快速开始

### 获取 API Key
访问个人设置页面，点击"生成 API Key"。

### 基本请求
\`\`\`bash
curl -H "Authorization: Bearer YOUR_API_KEY" \\
     https://api.example.com/v1/users
\`\`\`

## 端点列表

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | /users | 获取用户列表 |

```

转换结果将保留所有标题、列表、代码块和表格的格式。

## 支持的 Markdown 高级特性

### 代码块高亮

支持在代码块中指定编程语言，实现语法高亮：

```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
```

### 任务列表

虽然 Markdown 标准不包含任务列表，但某些编辑器支持：

- [x] 已完成的任务
- [ ] 未完成的任务

### 脚注和注释

```markdown
这是一个带脚注的句子[^1]。

[^1]: 这是脚注的内容。
```

## 最佳实践

### 1. 结构化文档

- 使用清晰的标题层级（H1 > H2 > H3）
- 避免跳跃式的标题级别
- 使用列表组织相关项目

### 2. 代码块指定语言

```markdown
\`\`\`python
# 指定语言有助于生成高质量的输出
def hello():
    print("Hello, World!")
\`\`\`
```

### 3. 合理使用格式

- 使用**粗体**强调重要内容
- 使用*斜体*表示引用或术语
- 使用`代码块`标记技术术语
- 使用> 引用块来突出重要信息

### 4. 表格规范

```markdown
| 列名1 | 列名2 | 列名3 |
|------|------|------|
| 左对齐 | 中对齐 | 右对齐 |
| :-- | :-: | --: |
```

## 常见问题解决

### Q: 转换后的 Word 文档格式不正确？
**A:** 某些复杂的 Markdown 扩展语法可能不被完全支持。建议使用标准 Markdown 语法或在 Word 中手动调整。

### Q: PDF 文件过大或转换缓慢？
**A:** 
- 确保输入的 Markdown 文件大小合理（建议 < 10MB）
- 减少图片数量和分辨率
- 避免过度使用复杂的嵌套结构

### Q: HTML 预览中样式不正确？
**A:** 这可能是由于某些特殊的 HTML 标签或 CSS 样式不兼容。您可以：
- 复制 HTML 代码手动调整样式
- 联系技术支持获得帮助

### Q: 可以转换包含图片的 Markdown 文件吗？
**A:** 
- 本地文件系统中的相对路径图片在转换时可能无法访问
- 建议使用网络 URL（http:// 或 https://）引用图片
- 如果使用相对路径，请确保图片与 Markdown 文件在同一目录
