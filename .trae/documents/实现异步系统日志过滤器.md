我们将在过滤器层增加系统日志记录功能，采用异步方式以保证接口性能，并对静态资源和文件下载进行特殊处理。

### 1. 启用异步支持
- **修改 `QuizApplication.java`**: 添加 `@EnableAsync` 注解，开启 Spring 的异步方法支持。

### 2. 扩展 SysLogService
- **修改 `SysLogService.java` 和 `SysLogServiceImpl.java`**:
    - 添加 `createSysLogAsync(SysLogCreateDto dto)` 方法。
    - 使用 `@Async` 注解标记该方法，确保日志入库操作在单独线程中执行，不阻塞 HTTP 响应。

### 3. 创建系统日志过滤器
- **新建 `com.ck.quiz.filter.SysLogFilter`**:
    - 继承 `OncePerRequestFilter` 确保每次请求只执行一次。
    - **请求/响应包装**: 使用 `ContentCachingRequestWrapper` 和 `ContentCachingResponseWrapper` 包装请求和响应，以便在不消耗流的情况下读取 Body 内容。
    - **排除静态资源**: 检查 URI 后缀（如 `.js`, `.css`, `.png`, `.ico` 等），直接放行不记录日志。
    - **文件下载处理**: 检查响应头 `Content-Type` 或 `Content-Disposition`，如果是文件下载，响应体记录为 `[File Content]` 而非实际二进制数据，防止内存溢出。
    - **日志收集**:
        - 记录 URI、Method、IP、User-Agent。
        - 计算请求耗时 (`costTime`)。
        - 从 `SecurityContext` 获取当前登录用户 (`createUser`)。
        - 记录请求参数和响应结果（截取合理长度）。
        - 记录异常信息（如有）。
    - **异步保存**: 在请求处理完成后 (`finally` 块)，调用 `SysLogService.createSysLogAsync`。

### 4. 注册过滤器
- **修改 `SecurityConfig.java`**:
    - 将 `SysLogFilter` 注册到 Spring Security 过滤器链中。
    - 顺序安排在 `JwtAuthenticationFilter` 之后，确保能获取到当前登录的用户信息。

### 5. 验证
- 启动服务，访问 API 接口，验证日志是否异步写入数据库。
- 访问静态资源，验证是否跳过记录。
- 测试文件下载接口，验证是否避免了记录二进制流。
