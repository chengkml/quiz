  PUT    /api/system-message/{messageId}/read
  PUT    /api/system-message/read-all
  DELETE /api/system-message/{messageId}
  DELETE /api/system-message/delete-all

【发送消息】
  POST   /api/system-message/send

🎓 使用示例
---------

【后端发送消息】
```java
@Autowired
private ISystemMessageService messageService;

// 发送单条
messageService.sendMessage("userId", "标题", "内容", "INFO");

// 批量发送
messageService.sendMessageBatch(userIds, "标题", "内容", "SUCCESS");

// 全部发送
messageService.sendMessageToAll("标题", "内容", "WARNING");
```

【前端获取消息】
```typescript
import { getUserMessages, getUnreadCount } from '@/pages/Notification/systemMessageApi';

const messages = await getUserMessages(0, 20);
const { unreadCount } = await getUnreadCount();
```

🚀 部署步骤
---------

1. 编译后端
   cd backend && ./gradlew clean build

2. 编译前端
   cd frontend && npm run build

3. 启动应用
   java -jar backend/build/libs/quiz-*.jar
